# profile

Luke Horton's personal site: **www.lukehorton.me**

Next.js (App Router) + TypeScript + Tailwind CSS v4, GSAP ScrollTrigger + Lenis smooth scroll, exported as a fully static site.

## Develop

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # static export -> ./out
npm start          # serve ./out locally
```

## Editing content

All copy lives in [`lib/content.ts`](lib/content.ts). Search for `TODO` to find the spots that still need details.

## Media

- **Hero video/image:** put `hero.mp4` (optional `hero.webm`) and/or `hero.jpg` in `public/media/`. They're picked up automatically at build time; without them a starfield placeholder is shown.
- **Photos:** originals live in `public/Photos/`. Web-sized WebP copies in `public/images/` are generated by `node scripts/optimize-images.mjs` (edit the job list in that script to add more).
- **Resume:** replace `public/Luke Horton Resume.pdf` (keep the filename, or update `site.resume`).

## Deploy

**GitHub Pages (current host):** `.github/workflows/deploy.yml` builds and publishes `./out` on every push to `main`.
One-time setup: repo **Settings → Pages → Build and deployment → Source: GitHub Actions**. The custom domain is kept via `public/CNAME`.

**Vercel:** import the repo; framework preset Next.js, no settings needed (output is static).

The previous hand-written site is kept for reference in `legacy/index.html` (not deployed).
